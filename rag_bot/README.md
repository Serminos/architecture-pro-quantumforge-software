# RAG-бот для базы знаний «Хроники Междумирья»

## Примечание об аппаратных ограничениях
Данная реализация использует Qwen2.5:7b (через Ollama) вместо запланированного в Задании 1 Qwen3-30B-A3B из-за ограничений тестового окружения:
- Тестовое железо: AMD Ryzen 9 9950X + NVIDIA GTX 1660 (6GB VRAM)
- Qwen3-30B-A3B требует ≥24GB VRAM (RTX 4090/A10)
- Qwen2.5:7b оптимально работает на доступном оборудовании
Для production-развёртывания в QuantumForge Software будет использоваться архитектура из Задания 1:
- Конфиденциальные данные → Qwen3-30B-A3B (локально, RTX 4090)
- Публичные данные → DeepSeek-V4 Flash (API)

## Описание
RAG-бот для семантического поиска и генерации ответов по базе знаний «Хроники Междумирья».
Бот использует:
- FAISS для векторного поиска
- BGE-M3 для эмбеддингов
- LLM (локальная через Ollama/HuggingFace или OpenAI)
- Few-shot и Chain-of-Thought для улучшения качества ответов

## Установка

### 1. Клонирование репозитория

```bash
git clone <your-repo>
cd architecture-pro-quantumforge-software
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка Ollama (для локального запуска)

```bash
# Установите Ollama с https://ollama.com
ollama pull qwen2.5:7b
```

## Конфигурация

В файле `rag_bot/config.py` можно настроить:

| Параметр       | Описание                     | Значение по умолчанию        |
|----------------|------------------------------|------------------------------|
| `LLM_TYPE`     | Тип LLM                      | `"ollama"`                   |
| `OLLAMA_MODEL` | Модель в Ollama              | `"qwen2.5:7b"`               |
| `HF_MODEL`     | Модель в HuggingFace         | `"Qwen/Qwen2.5-7B-Instruct"` |
| `OPENAI_MODEL` | Модель в OpenAI              | `"gpt-4o-mini"`              |
| `TOP_K`        | Количество чанков для поиска | `5`                          |

## Запуск

### 1. С Ollama (использовалось для примеров ниже)

```bash
# Убедитесь, что Ollama запущена
ollama serve

# Запуск бота
cd rag_bot
python rag_bot.py
```

### 2. С HuggingFace (локально)

```python
# В config.py измените:
LLM_TYPE = "huggingface"
HF_MODEL = "Qwen/Qwen2.5-7B-Instruct"
```

### 3. С OpenAI

```bash
# Установите API ключ
export OPENAI_API_KEY="sk-..."

# В config.py измените:
LLM_TYPE = "openai"
```

## Техники промптинга

### Few-shot

В промпт добавлены 2 примера из предметной области, которые показывают модели ожидаемый формат ответа с размышлениями:

```python
few_shot_examples = (
    "Вопрос: Кто такой Ivan Nebov?\n"
    "Размышления:\n1. Ключевые сущности: Ivan Nebov.\n2. В документах указано...\n"
    "Ответ: Ivan Nebov - главный герой...\n\n"

    "Вопрос: Что такое Svetomech?\n"
    "Размышления:\n1. Ключевые сущности: Svetomech.\n2. В документах сказано...\n"
    "Ответ: Svetomech - это оружие Ведунов...\n\n"
)
```

### Chain-of-Thought

Системный промпт требует пошагового рассуждения:

```python
system = (
    "Ты - помощник, специализирующийся на вселенной «Хроники Междумирья».\n"
    "Перед ответом ты ОБЯЗАН выполнить следующие шаги:\n"
    "Шаг 1: Определи ключевые сущности из вопроса.\n"
    "Шаг 2: Найди в предоставленных документах информацию по этим сущностям.\n"
    "Шаг 3: Сформулируй краткий ответ на основе фактов.\n"
    "Шаг 4: Если информации нет, честно скажи: «Я не знаю».\n"
)
```
