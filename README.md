# RAG-бот для компании QuantumForge Software

## 📖 Описание проекта

Разработан прототип интеллектуального RAG-бот для компании QuantumForge Software финско-эстонского разработчика SaaS-платформы «Digital Twin». Бот предназначен для быстрого и точного поиска информации в корпоративной базе знаний, содержащей ≈21 000 документов.

Ключевые задачи:
- Сокращение времени поиска информации сотрудниками
- Автоматизация ответов на часто задаваемые вопросы
- Выявление пробелов в документации
- Повышение продуктивности команды

### Задание 4. RAG-бот с техниками промптинга

Результат: Создан работающий RAG-бот с консольным интерфейсом.

Техники промптинга:
- Few-shot  2 примера из предметной области
- Chain-of-Thought  пошаговые рассуждения перед ответом

Пример диалога:

```
❓ Запрос: Кто такой Ivan Nebov?
💬 Ответ (за 8.4 сек):
Размышления:
1. Ключевые сущности: Ivan Nebov.
2. В документах указано, что Ivan Nebov  легендарный мастер-ведун...
Ответ: Ivan Nebov  главный герой, мастер-ведун...
```

Поддерживаемые LLM:
- Ollama (локально)
- HuggingFace (локально)
- OpenAI (API)

[Полный отчет](rag_bot/README.md)

### Задание 5. Защита от промпт-инъекций

| Уровень | Описание                                       |
|---------|------------------------------------------------|
| 0       | Без защиты (для отладки)                       |

Тестирование: Создан вредоносный файл `knowledge_base/final/malicious.txt`. На уровне 3 бот корректно отказывается отвечать на провокационные запросы.

### Задание 6. Автоматическое обновление базы знаний

Результат: Реализован автоматический пайплайн ежедневного обновления индекса.

| Компонент         | Описание                                    |
|-------------------|---------------------------------------------|
| Источник данных   | Папка `knowledge_base/incoming/`            |
| Планировщик       | Windows Task Scheduler (ежедневно в 20:10)  |
| Логирование       | `update_log.json` (JSON) + `update_log.txt` |
| Переиспользование | `chunk_documents()` из `build_index.py`     |

Пример лога:

```json
{
  "timestamp": "2026-07-06T21:30:44",
  "files": [{"name": "doc.txt", "hash": "abc123", "size_kb": 45.2}],
  "chunks_added": 12,
  "index_size": 3883,
  "errors": []
}
```

## 🚀 Быстрый старт

### Установка

```bash
# 1. Клонирование
git clone <repository>
cd architecture-pro-quantumforge-software

# 2. Создание виртуального окружения
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Установка Ollama (опционально)
ollama pull qwen2.5:7b
```

### Подготовка документов

```bash
# Загрузка очистка
cd knowledge_base
python download_and_clean.py

# Замена термов
python replace_terms
```

### Создание/Переиндексация индекса

```bash
cd vector_index
python build_index.py
```

### Запуск бота

```bash
# Без защиты
cd rag_bot
python rag_bot.py

# С защитой (уровень 3)
python rag_bot.py --security-level 3
```

### Автоматическое обновление

```bash
cd updater
python update_index.py
```

### Тестирование качества

```bash
cd analytics
python create_golden_set.py   # один раз
cd ../vector_index
python build_index.py          # после удаления файлов
cd ../analytics
python test_rag_bot.py
python analyze_results.py
```
